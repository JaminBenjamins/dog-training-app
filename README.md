# 🐕 DOGMAN UNLEASHED 254

Premium dog training appointment booking and payment system with M-Pesa integration.

## 🌟 Features

- Premium UI with modern design
- Interactive calendar booking
- M-Pesa STK Push integration
- Real-time payment tracking
- Auto-scrolling testimonials

## 🚀 Quick Start

```bash
npm install
npm start
```

## 📦 Deployment

This app is deployed on Vercel/GitHub Pages. See the live site at your deployment URL.

## 🛠️ Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js, Express
- Payment: M-Pesa Daraja API

## 🔐 Environment Variables

Create a `.env` file:
```
MPESA_CONSUMER_KEY=your_key
MPESA_CONSUMER_SECRET=your_secret
MPESA_SHORTCODE=your_shortcode
MPESA_PASSKEY=your_passkey
MPESA_CALLBACK_URL=your_callback_url
```
